# 안녕하세요.

저는 최기훈입니다.

전자재료공학을 전공했으며, 디지털 회로 설계와 검증에 관심이 있습니다.

대학교에서 반도체 공정과 전자회로를 공부했고, 그중 디지털 회로 설계에 가장 흥미를 느꼈습니다.

이후 FPGA와 임베디드 시스템을 공부하며 Verilog를 활용한 RTL 설계와 SystemVerilog 기반 검증 프로젝트를 진행했습니다.

## 학력
- 광운대학교 전자재료공학 전공
- On-Device AI 반도체 설계 및 검증 교육과정 수료

## 기술
- 언어: C, Verilog, SystemVerilog
- 개발 도구: Vivado, Vitis, Synopsys VCS, VS Code
- 버전 관리: Git, GitHub

## 관심 분야
- RTL 설계 및 검증
- FPGA 및 SoC 설계
- 임베디드 시스템

앞으로도 다양한 프로젝트를 경험하며 꾸준히 공부하고 싶습니다.
